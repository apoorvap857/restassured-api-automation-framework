# REST Assured API Automation Framework

A scalable and maintainable API Automation Testing Framework built using **Java**, **REST Assured**, **JUnit 5**, **Cucumber BDD**, and **Maven**. This framework follows industry best practices such as the Page Object Model equivalent for APIs, reusable utilities, configuration management, POJO serialization/deserialization, detailed reporting, and logging.

---

## Features

* REST Assured-based API automation
* Java and Maven project structure
* Cucumber BDD support
* JUnit 5 test execution
* POJO Serialization & Deserialization
* Request and Response Specifications
* JSON Schema Validation
* Configuration using Properties files
* Centralized API Endpoints
* Reusable Utility Classes
* Request Payload Builder
* Extent Reports integration
* Environment-based configuration
* Data-driven API testing
* Maven Surefire execution
* Easy integration with CI/CD pipelines

## Test Execution

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project:

```bash
cd APIFramework
```

Execute all tests:

```bash
mvn clean test
```
